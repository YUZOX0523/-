# 導入事例ページ 運用ガイド

法人リスキリング導入企業の最終報告資料から、見込み客向けの導入事例ページを作成・公開するためのワークフロー。

## 公開先

事例ページは `ai-adoption-survey/public/cases/` 配下の静的HTML。
mainにマージすると Vercel が自動デプロイし、以下のURLで公開される。

- 事例一覧: `https://shindan.digirise.ai/cases/`
- 株式会社トップ様: `https://shindan.digirise.ai/cases/top/`

HTMLは1ファイル完結(CSSインライン・外部依存はGoogle Fontsのみ)なので、
将来 digirise.ai 本体へ移す場合もファイルをそのまま持っていけばよい。

## 事例作成 → 公開のワークフロー

1. **素材受領**: 最終報告MTGの納品資料(PDF)を受け取る
2. **ドラフト生成**: PDFから定量データを抽出し、事例ページを作成する
   - 掲載する: 導入前後のKPI比較・推移グラフ・定着状況・活用業務の拡大・ROI試算・匿名化した受講者の声・プログラム概要
   - 掲載しない: 動画視聴状況、**受講者の個人名**(声はすべて匿名化する)、社外秘情報
3. **顧客へ掲載許可を依頼**: `<企業名>/approval-request.md` の依頼メールを送付
   - プレビューURL(VercelのプレビューデプロイURL または 公開前のスクリーンショット)を添える
   - 掲載承諾と同時に **ロゴデータと写真** の提供を依頼する
4. **承諾後、ロゴ・写真を置くだけで完成**:
   - ロゴ → `ai-adoption-survey/public/cases/<企業名>/client-logo.png`(背景透過PNG推奨)
   - 写真 → `ai-adoption-survey/public/cases/<企業名>/client-photo.jpg`(横長・1600px幅以上推奨)
   - ファイル名をこの通りにして置くだけで、ページに自動で表示される(無い間はスロットごと非表示でレイアウトは崩れない)
5. **公開**: mainへマージ → 自動デプロイ。`cases/index.html` の一覧にカードを追加する

## 新しい事例を追加するとき

1. `ai-adoption-survey/public/cases/top/index.html` を `cases/<新企業名>/index.html` にコピー
2. 企業名・KPI数値・グラフ・声・注記を最終報告資料の値に差し替え
3. `case-studies/<新企業名>/approval-request.md` を `top/` のものをベースに作成
4. 上記ワークフロー3以降を実施

## 掲載前チェックリスト

- [ ] 個人名が一切載っていない(受講者の声は匿名化済みか)
- [ ] 数値がすべて最終報告資料と一致している
- [ ] ROI試算の前提(時給換算・期間・助成金)の注記がある
- [ ] 「成果を保証するものではありません」の注記がある
- [ ] 顧客の書面(メール可)による掲載承諾を得ている
- [ ] 企業名・ロゴ・写真の使用許可を得ている
