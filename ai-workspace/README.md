# DigiRise AI ワークスペース

AI未導入企業向けの**オールインワン社内AIツール**。
「Claude（チャット）× Claude Cowork（資料分析）× Claude Code（コード支援）」のいいとこ取りを、誰でも使えるシンプルなUIで1つにまとめたものです。

## 特徴

### 1. 誰でも使える（らくらくフォン方針）
- ホーム画面は「今日は何をしますか？」+ 大きなボタンだけ
- 「モデル」「トークン」などの専門用語は利用者画面に一切出さない
- 大きな文字・大きなボタン・1画面1アクション

### 2. 単体導入でもセキュリティが堅牢
| 項目 | 実装 |
|---|---|
| データの保存先 | すべて自社サーバー内のSQLite（外部DBなし）。外部通信はClaude APIのみ |
| AIへの学習利用 | Claude APIに送信したデータはデフォルトで学習に使われない |
| 認証 | scryptによるパスワードハッシュ、HttpOnly + SameSite=Strict Cookie、セッション12時間 |
| 総当たり対策 | ログイン試行のレート制限（10回/10分/IP） |
| 監査ログ | ログイン・チャット実行・管理操作をすべて記録（誰が・いつ・どこから） |
| アカウント統制 | 管理者によるユーザー追加・停止（退職者の即時無効化） |
| その他 | CSP等のセキュリティヘッダー、添付10MB上限、入力サイズ制限 |

### 3. 1ID = 月1,000円で売っても利益が出るコスト構造
利益はコード上の2つの仕組みで**構造的に保証**されます。

**(a) 用途別モデル自動振り分け**（利用者はモデルを意識しない）

| ボタン | 使用モデル | 単価（入力/出力 per 1Mトークン） |
|---|---|---|
| 質問・相談 / 文章作成 | Claude Haiku 4.5 | $1 / $5 |
| 資料の要約・データ分析 | Claude Sonnet 5 | $3 / $15 |
| コードを書く・直す | Claude Sonnet 5 | $3 / $15 |
| 高度な分析（既定OFF） | Claude Opus 4.8 | $5 / $25 |

**(b) ユーザーごとの月次コスト上限**
- 既定 500円/月（`DEFAULT_MONTHLY_BUDGET_JPY`）。超えると当月は自動停止 → **最悪ケースでも粗利50%を下回らない**
- 実際の平均利用は月100〜300円程度に収まる想定（毎日20〜30回の利用でも上限内）
- 管理者画面からユーザー単位で上限変更可能

さらにシステムプロンプトにプロンプトキャッシュを適用し、繰り返し部分の入力コストを約1/10に削減しています。

## セットアップ

**管理者アカウントは、初回にブラウザで開いたときに表示される「初期設定」画面から作成します**（設定ファイルにパスワードを書く必要はありません）。以降のユーザー追加は 管理画面 → ユーザー管理 から行います。

### 方法A: ブラウザだけでデモ環境を立てる（いちばん簡単・ターミナル不要）

1. [render.com](https://render.com) にGitHubアカウントでサインアップ（無料）
2. ダッシュボードで **New + → Blueprint** → このリポジトリ（YUZOX0523/-）を選択
3. 環境変数 `ANTHROPIC_API_KEY` にAnthropic APIキーを入力して **Apply**
4. 数分待つと `https://xxxx.onrender.com` のURLが発行される → 開くと初期設定画面

※ 無料プランは再デプロイでデータが消えるためデモ専用。本番は方法B/Cで。

### 方法B: 手元のPCで動かす（要 Node.js 22.5以上）

```bash
cd ai-workspace
npm install
cp .env.example .env
# .env を編集: ANTHROPIC_API_KEY にAPIキーを設定（それだけ）
npm start
# → http://localhost:3100 を開くと初期設定画面
```

### 方法C: 顧客向け本番（VPS + Docker）

```bash
docker build -t ai-workspace .
docker run -d -p 3100:3100 --env-file .env -v ai-workspace-data:/app/data ai-workspace
```

### 管理者パスワードを忘れたとき（デモ環境）

サーバーを止めて `data` フォルダを削除して再起動すると、まっさらな状態に戻り初期設定からやり直せます:

```bash
rm -rf data && npm start
```

※ 会話履歴・ユーザーもすべて消えます。本番運用ではデータのバックアップを取ってください。

## 画面構成

- `/login.html` — ログイン
- `/` — ホーム（やりたいことボタン + 利用量ゲージ + 会話履歴）
- `/admin.html` — 管理画面（利用状況・コスト / ユーザー管理 / 監査ログ）※管理者のみ

## 収益シミュレーション（50名の会社に導入した場合）

| 項目 | 金額 |
|---|---|
| 売上（50ID × 1,000円） | 50,000円/月 |
| APIコスト（平均200円/人と仮定） | ▲10,000円/月 |
| APIコスト（全員が上限500円に達した最悪ケース） | ▲25,000円/月 |
| 粗利 | 25,000〜40,000円/月（**粗利率 50〜80%**） |

※ サーバー費用（VPS 1台 1,000〜2,000円/月程度）は別途。1社1サーバーでもテナント分離として売りにできます。
