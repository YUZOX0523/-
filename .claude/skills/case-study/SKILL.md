# /case-study — 導入事例原稿 自動生成スキル

最終報告MTG資料(PDF)を入力として、見込み客向けの導入事例**原稿ファイル**を生成する。
公開は必ず「顧客の掲載承諾」を得てから。**承諾前に原稿を公開してはならない。**

## 入力

- ユーザーがアップロードした最終報告MTG資料のPDF(全ページをReadで読み込む。20ページ超は分割して読む)
- 対象企業名はPDFの表紙(「◯◯御中」)から取得する

## 生成フロー

### 1. PDFから定量データを抽出

以下を必ず拾う(値はPDF記載のものをそのまま使う。**推測・創作は禁止**):

- 導入前後のKPI: AI活用業務数/週あたり削減時間/AI活用頻度/研修役立ち度
- 回ごとの推移データ(削減時間・活用頻度)
- 定着状況(週◯日以上利用率・社内共有率など)
- 実務で試したAI活用の項目と割合
- 活用業務の広がり(導入前→導入後の対比)
- ROI試算(時間創出価値・実質負担額・ROIと計算前提)
- 受講者の声(匿名化して使う)
- プログラムの実施内容・期間・受講人数

### 2. 掲載してはいけないもの(必須ルール)

- **動画視聴状況**(個人単位の進捗データ)
- **受講者の個人名**(声はすべて「受講者アンケートより」として匿名化)
- 社外秘とわかる情報(個別の商談内容・取引先名など)

### 3. 原稿ファイルの生成(2形式)

**(a) チェック用原稿(Markdown)** と **(b) WordPress入稿用(Gutenbergブロックマークアップ)** の2つを必ず生成する。

(a) `case-studies/TEMPLATE.md` の構成に従い、`case-studies/<企業スラッグ>/draft.md` に保存
- frontmatter(company/program/period/participants/source/status: draft)を記入
- タイトルには最も強い数字を入れる(例「AIを使う業務が約4.1倍」)
- **画像挿入位置マーカーを必ず2箇所入れる**:
  - `【画像挿入位置①:企業ロゴ】` — 原稿冒頭(タイトルの直前)
  - `【画像挿入位置②:社内または社員の写真】` — リード文の直後
  - それぞれに支給素材の推奨仕様(透過PNG/横長写真)を注記する
- 末尾に注記2点を必ず入れる: 「成果を保証するものではありません」+ ROI試算の前提条件

(b) `case-studies/<企業スラッグ>/wordpress.html` に、WordPressのコードエディターへ全文コピペするだけで記事になる**Gutenbergブロックマークアップ**を保存(お手本: `case-studies/top/wordpress.html`)
- 冒頭のHTMLコメントに貼り付け手順と「タイトル欄用のタイトル」を記載
- 見出しは h2/h3、KPI・推移はテーブルブロック、声は引用ブロック
- 画像挿入位置は太字の指示段落として埋め込む(①企業ロゴ/②宣材写真。差し替え後に削除する旨を明記)
- テーマのスタイルを継承させるため、インラインCSSは書かない

### 4. 掲載許可依頼文の生成

`case-studies/<企業スラッグ>/approval-request.md` を作成(`case-studies/top/approval-request.md` をお手本にする):

- 依頼メール文面(掲載予定の内容一覧・掲載しない内容を明記)
- **承諾と同時にロゴデータと写真の支給を依頼する**(これが揃えば挿入するだけで完成)
- 承諾記録表(承諾日・承諾者・承諾方法・企業名/ロゴ/写真の可否)

### 5. ユーザーへの出力

1. 原稿ファイルのパスと内容サマリー(抽出したKPI一覧)
2. 掲載許可依頼メールのドラフト
3. チェックリスト:
   - [ ] 数値がPDFと一致しているか(ユーザー目視確認)
   - [ ] 個人名・動画視聴状況が入っていないか
   - [ ] 顧客へ依頼メールを送付
   - [ ] 承諾記録を approval-request.md に記入
   - [ ] ロゴ・写真を受領し、原稿+素材をサイト担当へ引き渡し(配置位置は原稿のマーカー参照)

## 承諾後の反映(公開はWordPressで社内担当が手動)

- 受領したロゴ・宣材写真は `case-studies/<企業スラッグ>/assets/` に保存
- 原稿の frontmatter を `status: approved` にし、`approved_date` を記入
- 社内担当がWordPressで公開する(このスキルはデプロイ・公開を行わない):
  1. WordPressで新規投稿 → コードエディター → `wordpress.html` の中身を全文貼り付け
  2. タイトル欄に冒頭コメント記載のタイトルを入力、アイキャッチに宣材写真を設定
  3. 記事内の【画像挿入位置①/②】の指示段落を、アップロードしたロゴ・宣材写真の画像ブロックに差し替え
- 公開されたら `status: published` に更新

## このスキルが編集してよい場所

`case-studies/` 配下のみ。
