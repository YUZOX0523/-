# プレスリリース執筆スタイルガイド（デジライズ広報）

原稿生成時は必ずこのガイドに従うこと。`scripts/seo-check.mjs` の採点基準はこのガイドと同期している。

## 1. タイトル（最重要・転載率の8割はここで決まる）

- **30〜40字**を目安に（PR TIMESの上限は100字だが、Google検索結果は約30字で切れる）
- **主要キーワードを先頭20字以内**に置く（SEOの基本。「デジライズ、生成AI研修〜」のように社名→キーワードの順が定石）
- **数字を必ず1つ入れる**: 「導入500社」「3倍」「68%」「3日間」— 数字のあるタイトルは編集者の目に留まりやすい
- **体言止め**にする: 「〜を提供開始」「〜が3倍に」（「〜しました。」は弱い）
- 改行不可・記号の乱用禁止（【】は1組まで、「！」は原則使わない）
- サブタイトル（100字以内）で補足: 対象・時期・限定性・実績

## 2. 構成（逆ピラミッド）

結論 → 詳細 → 背景 の順。編集者は最初の5行で記事化するか判断する。

1. **リード文（200〜400字）**: 5W2Hを凝縮。1文目に「会社名＋何を」。ここだけ読めば全体がわかる状態に
2. **本文（1,500〜3,000字)**: 小見出し（###）を3個以上。1セクション600字以内
3. **会社概要・お問い合わせ先**: 必ず末尾に（company.md から展開）

## 3. 転載・メディア掲載されやすくする要素

- **独自データ**: 自社調査の数字（n=300以上）は引用されやすさ最強。調査リリース（survey テンプレート）は月1本が理想
- **引用できるコメント**: 代表・顧客の「」付きコメントを必ず入れる（メディアがそのまま記事に使える）
- **時事性フック**: 業界ニュース・季節・制度改正と接続する（/pr-watch のレポートからネタを拾う）
- **画像3枚以上**: メイン画像1200×630px。グラフは出典（「株式会社デジライズ調べ」）を画像内に焼き込むと転載時も出典が残る
- **引用条件の明記**: 調査リリースには「出典明記でグラフ転載可」と書くと媒体が使いやすい

## 4. 配信タイミング

- **曜日**: 火・水・木 が定石（月曜午前は埋もれる、金曜夕方以降は読まれない）
- **時間帯**: **午前10〜11時台**が第一候補（メディアの朝会後に乗る）。次点は14時台
- 大型発表・大きなニュースがある日は避ける
- イベント告知は開催の2〜4週間前、導入事例・調査はネタが新しいうちに
- PR TIMESの予約配信機能を使い、上記の時間に設定する

## 5. 表現ルール（景表法・信頼性）

- **「業界初」「日本初」「No.1」「唯一」**: 使用する場合は直後に必ず「※自社調べ（2026年◯月、比較対象◯◯、n=◯◯）」等の根拠注記。根拠がなければ使わない
- **「必ず」「絶対」「100%」等の断定**: 使用禁止（景表法・薬機法的リスク）
- **「圧倒的」「究極」「最強」等の誇大副詞**: 原則使わず、具体的な数字に置き換える
- 他社・競合をおとしめる比較表現は使わない
- 数字には可能な限り出典・時点を添える

## 6. SEO細則

- 主要キーワードはタイトル・サブタイトル・リード文・小見出しに自然に分散（詰め込みすぎない）
- 共起語を本文に散らす（例: 「生成AI研修」なら「プロンプト」「ChatGPT」「人材育成」「DX」）
- 固有名詞（サービス名・人名・地名）を正確に書く — 検索とファクトチェックの両方に効く
- 公式サイト・申込ページへのリンクはURLをそのまま記載（PR TIMESでは自動リンク化される）

## 7. 配信頻度の目安

- 月2〜4本を安定して出す（沈黙期間を作らない）
- ネタの型ローテーション例: 調査リリース → 導入事例 → サービス/イベント → 時事コメント
- ネタ切れ時は /pr-watch を実行して業界動向からネタを発掘する
